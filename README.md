## วิธีเปิดเว็บไซต์

1. เปิดโฟลเดอร์ portfolio ด้วย VS Code

2. ตรวจสอบว่าไฟล์ทั้งหมดอยู่ในตำแหน่งที่ถูกต้อง

3. ใส่ไฟล์ background.mp4 ไว้ใน

assets/background.mp4

4. ใส่รูปเกมไว้ใน

assets/rov.jpg
assets/roblox.jpg
assets/valorant.jpg

5. ติดตั้ง Extension "Live Server" ใน VS Code

6. คลิกขวาที่

index.html

แล้วเลือก

Open with Live Server

เว็บไซต์จะเปิดขึ้นใน Browser

## หากไม่มี Background Video
